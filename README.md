# ML-based-Intrution-detection-system

## Overview

A machine learning-based Network Intrusion Detection System (NIDS) developed using the CIC-IDS2018 dataset to classify network traffic as benign or malicious.

## Models

The following machine learning models were implemented:

- Decision Tree
- Random Forest
- XGBoost

## Workflow

Dataset → Data Cleaning → Feature Engineering → Model Training → Evaluation


## Results

| Model | Accuracy |
|---|---:|
| Decision Tree | 99.9454% |
| Random Forest | 99.9971% |
| XGBoost | 99.9986% |

- Python

- XGBoost
